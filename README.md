
2021年度 信创大比武作获奖作品  Music-Score-Editor

Music-Score-Editor 是一款基于 WPS OFFICE WORD 开发的一款乐谱编辑插件，离线模式打包进行发布和安装，支持没有服务器也可以正常使用。

技术栈：原始 Javascript + jq、Vue、Cli、vba 等 共同实现
